# 挖穿地心公司设计规格

## 产品边界

- 类型：H5/PWA 放置经营小游戏。
- 视觉：原创像素风矿井剖面，代码绘制，不依赖外部游戏美术。
- 平台：手机竖屏和 PC 横屏共用一个响应式版本。
- 技术：TypeScript、Vite、Phaser 4.2.1、HTML/CSS UI、localStorage 版本化存档。
- 首版商业能力：模拟激励广告适配层，不接真实 SDK，不收集用户数据。

## 核心规则

三条生产线均以离散周期工作。手动模式只在玩家点击时启动周期；自动模式在有输入时持续启动周期，无输入时等待。

1. 钻探周期完成后，把当前矿层的一批矿石加入地下库存。
2. 起吊周期完成后，把不超过卷扬机容量的矿石移到地面库存。
3. 运输周期完成后，把不超过卡车容量的矿石送达总部，按矿石价值结算金币。

库存采用 `units` 与 `totalValue` 表示，避免为无限矿层保存无限批次对象。每次转移按比例保留平均单位价值。

## 数值原则

- 第 `n` 层单位价值：约 `3.2 * 1.32^(n-1)`。
- 第 `n` 层基础钻探时间：约 `1.4 * 1.08^(n-1)` 秒。
- 更深矿层的价值增速高于时间增速，保证解锁后值得立即使用。
- 装备升级费用指数增长，速度与容量分阶段增长。
- 离线模拟使用与在线一致的自动化规则，并以 1 秒步长限制到 12 小时。
- 广告倍率只乘收益，不提供固定金币，并自动适配当前矿层。

## 状态模型

- `money`、`lifetimeEarnings`、`companyXp`。
- `deepestLayer`、`currentLayer`、`museum`。
- 三条线各自的 `level`、`progress`、`automated`、`queued`。
- 地下库存、地面库存。
- 9 名工头解锁状态。
- 在线加速剩余秒数、模拟广告状态。
- 每日任务、教程步骤、设置和统计数据。
- `version`、`savedAt`、`lastSeenAt`。

规则模块不得依赖 Phaser 或 DOM，必须能通过 Node 环境单元测试。

## 存档

- localStorage 主键 `mine-company-save-v1`，备份键 `mine-company-save-backup-v1`。
- JSON 包含整数版本号。
- 保存前先把旧主存档复制到备份键，再写新存档。
- 读取失败时尝试备份；旧版本通过纯函数逐级迁移。
- 拒绝来自更高版本的存档，并保留原始数据。
- 自动保存节流为 5 秒，并在关键购买、解锁和页面隐藏时立即保存。

## 广告适配层

`RewardedAdAdapter` 只暴露：

- `isAvailable()`。
- `show(placement)`，返回 `completed | skipped | unavailable`。

首版实现为可测试的模拟适配器。在线产出倍率为 2 倍，奖励 15 分钟，最多储备 30 分钟，不叠倍率。离线报告最多额外补 100%，且只有基础离线收益已经计算后才出现入口。

## 体验与无障碍

- 新手七步任务每次只强调一个目标。
- 推荐升级为一键购买当前最划算项目。
- 支持键盘 `Space` 与 `1/2/3`。
- 弹窗支持 `Escape` 关闭、焦点回到触发按钮。
- 音效、屏幕抖动、减少闪烁均可独立关闭。
- 所有关键数字同时使用图标或文字，不只依赖颜色。

## 验收

- 规则单元测试覆盖三线库存、自动生产、升级、离线、广告、存档迁移。
- `npm run typecheck`、`npm test`、`npm run build` 全部通过。
- 五种目标分辨率无横向溢出、关键文字不重叠、画布非空。
- 浏览器控制台无未处理错误。
- 不加载第三方游戏图片、音频或字体，不复制现有作品素材。
